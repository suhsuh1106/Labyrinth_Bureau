# 옛 용병단 게임 자료

여기 있는 문서는 옛 전제("용병단 행정관", `company.html`, `src/core/` · `src/ui/co/`)의 것이다. 지금 게임(미궁관리국, `index.html`, `src/bureau/` · `src/ui/bureau/`)의 기준이 **아니다**.

- 미궁관리국 작업에서는 이 폴더를 참조하지 않는다. 낱말(용병단 · 행정관 · 영주청 · 층 · 채집품 등)과 규칙이 지금 게임과 다르다.
- 옛 게임 코드를 고칠 때만 읽는다. 그때의 지침은 `CLAUDE-company.md`.
- 지금 게임의 기준: `docs/systems.md`(통합 기획서), `docs/bureau.md`(엔진 기록), `docs/world.md`(세계관 · 글).

| 파일 | 내용 |
|---|---|
| `CLAUDE-company.md` | 옛 게임의 구조 · 규칙 · 방향 (옛 루트 CLAUDE.md) |
| `README-company.md` | 옛 루트 README |
| `plan.md` | 만들어 온 순서와 단계별 기록 |
| `world.md` | 옛 세계관 (하르덴 백작령 · 회색늑대 용병단) |
| `board.md` · `maps.md` | 판 화면 · 작전 지도 |
| `zones.md` · `missions.md` | 구역 · 탐사 엔진 |
| `teams.md` · `companies.md` · `patrons.md` · `pillars.md` | 조와 조장 · 경쟁 용병단 · 후원 세력 · 기둥 |
