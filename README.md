# Labyrinth Bureau

> 제국의 신설 부서 **미궁 관리국**의 장이 되어, 예산안 한 장으로 미궁과 그 주변의 이해관계를 다스리는 경영 시뮬레이션.

전 세계에 미궁이 갑자기 열리기 시작했습니다. 처음에는 모두 미궁을 닫으려 했지만, 그 안에서 쏟아지는 자원 때문에 "관리하자"는 쪽으로 기울었습니다. 지방에 미궁이 생기자 영주들이 경제력과 군사력을 쥐기 시작했고, 제국은 새 부서와 함께 유망한 행정관 한 명을 변경으로 보냅니다. 그게 플레이어입니다.

목표는 성과를 내고 수도로 돌아가는 것. 하지만 장부를 오래 들여다볼수록, 이 미궁에서 가장 효율적인 해법이 무엇인지 알게 됩니다.

## 핵심 재미

- **이해관계를 읽는다.** 상단과 교회는 저마다의 셈으로 움직입니다. 단가가 오르면 "진짜 원가가 오른 건가, 짠 건가?"를 서류와 장부로 추리합니다.
- **직접 움직이지 않고, 규칙과 돈으로 움직이게 한다.** 용병은 직원이 아니라 면허를 받고 들어오는 자유 용병입니다. 관리국은 통행세, 예산, 공략본, 시설로 미궁 생태계를 간접적으로 키웁니다.
- **추리를 선언하고 확인받는다.** 현장 증언으로 층의 약점을 추리하고, 통계로 확인한 뒤 공략본을 발간합니다. 맞으면 용병들이 이 미궁의 미래를 믿기 시작합니다.
- **누군가의 이권을 건드리지 않는 결정은 없다.** 시설 하나, 헌금 한 줄, 감찰 한 번이 세력의 태도를 바꿉니다.

## 해 보기

웹 브라우저 게임입니다 (TypeScript + Vite).

- **바로 하기**: main에 머지될 때마다 GitHub Pages에 올라갑니다. 주소는 `https://suhsuh1106.github.io/Labyrinth_Bureau/` 입니다.
- **내 컴퓨터에서**: Node 22가 필요합니다.

  ```bash
  npm install
  npm run dev        # 개발 서버 (http://localhost:5173)
  ```

### 개발 명령

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버. 고치면 바로 반영 |
| `npm test` | 테스트: 옛 프로토타입과 동작 비교, 장부 일치, 모든 탭 렌더, 저장 불러오기 |
| `npm run typecheck` | 타입 검사 |

| `npm run build` | 배포용 빌드 (`dist/`) |

PR을 올리면 GitHub Actions가 타입 검사, 테스트, 빌드, 봇 시뮬레이션을 돌립니다.

### 첫 몇 달: 개척기

관리국은 이름뿐인 상태로 시작합니다. 개척 용병 20명과 수도의 초기 예산 25,000G가 전부입니다. 예산안의 **개척 사업**에서 면허 사무소, 포션 공급망, 전리품 판로를 고르고 착수합니다. 세 가지가 서면 관리국이 정식으로 문을 열고, 지은 것에 따라 예산안의 줄이 하나씩 열립니다. 누구에게 공급과 판로를 맡겼는지는 플래그로 남아 이후의 담합과 세력 관계를 바꿉니다.

### 한 달의 흐름

화면은 관리국장의 책상입니다. 물건을 누르면 그 서류를 집어 들어 크게 읽습니다.

1. 왼쪽 **서류함**에서 이번 달 소식, 안건, 제안, 장부 사본, 지난달 결산을 읽습니다. 새 서류가 오면 서류함에 표시가 붙습니다.
2. **서신**(세력 동향), **미궁 지도**(탐사 기록), **용사 명부**, **시설 도면**, **장부**(수입·지출), **달력**(임기 목표)으로 판세를 살피고 공략본이나 시설을 결정합니다.
3. 가운데 **예산안**을 집어 들어 금액을 고치고, 오른쪽 아래 **도장**을 찍으면 한 달이 흐릅니다.
4. 결재가 끝나면 그달의 순간들이 한 장씩 올라옵니다. 매달 오는 **귀환 보고**(파티마다 누구를 데려가 어떻게 됐는지, 공략본을 따른 조의 성적), 그리고 일이 있던 달에만 **공략본 적중·빗나감**, **용사 부고**, 봉랍을 뜯는 **임기 평가 서신**이 이어집니다. 건너뛰기나 Esc로 한 번에 넘길 수 있고, 명패의 단추로 효과음을 끌 수 있습니다. 처음 겪은 큰 순간은 명패 아래 기념품 선반에 걸립니다.
5. 이어서 그달의 **변경 일보**가 책상 위로 날아옵니다. 큰 일이 있던 달은 호외 도장이 찍혀 옵니다. 지난 호는 책상 왼쪽 신문을 집어 넘겨 봅니다.

### 들어 있는 시스템

| 시스템 | 내용 |
|---|---|
| 개척기 | 면허 사무소(천막/석조), 포션 공급망(상단 위주/교회 위주/경쟁 입찰), 전리품 판로(상단 매입/수도 직거래/교회 성물), 1층 측량, 모집 공고(변경/남부/수도). 판로가 열리기 전 전리품은 쌓였다가 개통하는 달에 한꺼번에 팔립니다. 부임 직후 대사제의 축성 제안과 상단 조합장의 환영 선물이 첫 안건으로 옵니다 |
| 예산안 | 보급(상단·교회 포션 구매, 포션 공방, 식량, 장비 정비, 운송), 탐사 지원(공략 지원금, 장비 대여, 사제 파견 요청, 직업 장려금), 층별 입장료, 교회 헌금, 정보·감찰(시장 조사비, 감찰비), 고정 지출 여섯 묶음으로 나뉘고, 묶음마다 소계가 붙으며 접었다 펼 수 있습니다. 필요량보다 많이 산 포션은 창고에 비축됩니다 |
| 보급 | 포션(용병당 2병), 식량(용병당 1인분, 교회), 장비 정비(파티당, 상단), 운송(파티당, 깊은 층일수록 비쌈) 네 가지를 금액으로 삽니다. 포션이 모자라면 사망, 식량은 이탈, 정비는 성공률, 운송은 전리품이 줄어듭니다. 용병이 늘고 층이 깊어지면 같은 돈으로 100%를 못 채우니, 어디를 깎을지 골라야 합니다. 결산의 보급 충족 보고가 물품별로 무엇을 잃었는지 보여 줍니다 |
| 세력 관계 | 상단과 교회의 호의와 서운함이 양방향으로 움직이고, 가만히 두면 무덤덤으로 돌아갑니다. 무엇을 반기고 싫어하는지는 겪어 봐야 기록됩니다 |
| 담합 | 기회·동기·감시 공백·핑계가 맞으면 상단과 교회가 스스로 담합합니다. 헌금으로 교회를 빼 오거나, 감찰로 압박하거나, 공방으로 의존도를 낮춰 끝냅니다 |
| 용병 조합 | 사망이 잦거나 신뢰가 낮거나, 용병을 박하게 대한 기록(위로금 거절, 검문소 등)이 쌓이면 조합이 결성돼 신규 면허를 보이콧합니다 |
| 전리품 누수 | 전리품 수입이 조금씩 샙니다. 상단 감정 차익인지 용병 밀반출인지는 숨겨져 있어, 서기의 메모·결산의 파티당 수입·감찰 장부로 추리해 검문 또는 고발합니다. 틀리면 대가가 따릅니다 |
| 이웃 영주 | 관리국이 잘되면 하르덴 백작이 용병을 영지 경비대로 끌어갑니다. 밀약, 수도에 고발, 장려금으로 맞서기 중에서 고릅니다. 밀약은 나중에 수도의 감찰로 돌아옵니다 |
| 안건 | 지금까지의 선택이 플래그로 쌓이면 그에 맞는 안건이 서류함에 올라옵니다 (예: 헌금으로 담합을 깼다면 상단의 손실 보전 요구, 감찰을 한 적이 있다면 장부를 내미는 선택지). 고르지 않고 결재하면 기본 처리됩니다 |
| 세력의 제안 | 호의적인 세력은 독점 공급 계약, 견습 사제 파견 같은 제안을 먼저 보내옵니다 |
| 탐사와 공략본 | 5개 층마다 판마다 다른 괴물이 숨어 있습니다. 증언은 파티가 실제로 데려간 직업·장비에서만 나오고, 궁금한 조건은 **시험 탐사비**로 직접 시험합니다. 역효과 조건과 겉모습이 같은 함정 괴물이 있고, 교회와 상단은 자기 물건이 팔리는 쪽으로 증언을 섞습니다 |
| 세 겹의 비밀 | 층마다 약점, 습성(돌아오는 달·몰린 달에 사나워짐, 또는 짝 조건), 근원이 있습니다. 근원을 찾으면 그 층을 **봉인**할지 **채굴**할지 시설로 정하고, 봉인 이야기 조각이 열립니다. 같은 공략을 오래 쓰면 괴물이 적응해 약점이 바뀝니다 |
| 층별 입장료 | 용병은 층마다 기대 전리품, 사망 위험, 붐빔, 입장료를 따져 갈 곳을 고릅니다. 개척은 가장 깊은 층에서만 진행되니, 얕은 층에 입장료를 매기거나 깊은 층에 보조금을 줘서 파티를 움직입니다 |
| 직업·장비 수급 | 공략본이 마법사를 넣으라 해도 용병 중 마법사가 모자라면 따를 수 없습니다. 장비는 상단에서 빌리고(담합 때는 대여료도 오름), 사제는 교회에 파견을 요청하고(교회가 서운하면 덜 보냄), 나머지 직업은 장려금으로 불러옵니다 |
| 용사 파티 | 용사 후원금으로 공고를 걸면 지원자가 옵니다. 실력·몸값·출신(용병, 교회 추천, 상단 추천)·야심을 보고 명단을 짜고, 후원금이 몸값 합계를 넘으면 결성됩니다. 용사는 늘 가장 깊은 층으로 가서 개척을 이끌고, 길을 먼저 열면 새 층에 용병이 뒤따릅니다. 장비 지원(상단)과 홍보비도 예산 줄입니다 |
| 명성 | 용사의 승전과 길 개척으로 오르고 죽음·해체·배신으로 떨어집니다. 높으면 용병이 더 오고, 수도 평가가 너그러워집니다. 몸값을 덜 주면 사기가 떨어져 파티가 흩어지고, 백작이나 상단이 야심 큰 용사를 빼 가거나, 교회가 교회 출신 용사의 죽음을 기리거나 관리국 탓으로 돌리는 일이 조건이 맞을 때만 일어납니다 |
| 개척 시설 | 착공비를 한 번에 내고 공사 기간을 기다리면 완공 뒤 매달 유지비가 나갑니다. 시설마다 누군가의 이권을 건드립니다 |
| 변경 일보 | 상인 조합이 매달 내는 신문. 그달 가장 큰 일이 1면에 오르고, 이달의 숫자(포션 값, 원정 성공률, 사망, 용병, 금고), 단신, 세력 동향, 용병의 독자 투고, 현장 증언에서 나온 소문, 광고가 실립니다. 장사 쪽 눈으로 쓰는 신문이라 포션 값이 오르면 변명하고, 판로가 막히면 관리국을 재촉합니다. 지난 기록만 읽어 만들기 때문에 게임 상태에 아무것도 남기지 않고, 지난 호도 같은 모습으로 다시 펼쳐집니다 |
| 임기 평가 | 12개월마다 수도가 금고, 개척, 용병 수, 사망, 세력 관계를 평가합니다. 결과에 따라 보조금, 경고, 소환이 이어집니다 |
| 해마다 한 막 | 1년 차 포션 담합, 2년 차 교회 종파 분열(개혁·보수·타협), 미궁의 이상 징후(날짜가 아니라 꺼낸 양에 따른 압력으로) |
