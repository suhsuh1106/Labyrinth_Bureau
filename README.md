# Labyrinth Bureau

> 서부 변경에 미궁이 열렸다. 큰 용병단 일곱 곳과 수십 개의 군소 용병대가 같은 층에서 캐고 같은 시장에 판다.
> 당신은 그중 작은 용병단, **회색늑대 용병단의 행정관**이다.

미궁 용병단 경영 워게임입니다. 단장은 칼을 들고, 행정관은 미궁에 들어가지 않고 돈과 사람을 숫자로 나눕니다. 36개월 뒤 **평가액**(금고)으로 순위를 겨룹니다. 세계관은 `docs/world.md`, 만들어 온 순서와 단계별 기록은 `docs/plan.md`에 있습니다.

## 핵심 재미

- **숫자로 정한다.** 층마다 몇 조를 보낼지, 포션과 장비를 얼마나 사 둘지, 훈련·거점·후원·근원에 얼마를 넣을지. 대사를 고르는 선택지는 없습니다.
- **모두가 같은 판에서 겨룬다.** 한 층에 몰리면 나눠 갖고, 다 같이 많이 팔면 값이 떨어집니다. 경쟁 용병단은 성향대로 움직이고 지난달 결과에 반응합니다.
- **고래들 사이의 새우.** 혼자서는 시장을 못 움직입니다. 눈치(시세와 경쟁자의 수 읽기)와 정치(상단·교회와의 관계, 담합 깨기, 근원 봉인)로 큰 흐름을 조금씩 돌립니다.
- **먼저 알아낸 쪽이 번다.** 우리 직영 파티만 현장 증언과 구성별 성공 기록을 가져옵니다. 몬스터의 약점을 추리해 편성 지침으로 삼으면, 경쟁자가 깨치기 전까지 앞서 갑니다.

## 해 보기

웹 브라우저 게임입니다 (TypeScript + Vite, 프레임워크 없음).

- **바로 하기**: main에 머지될 때마다 GitHub Pages에 올라갑니다. `https://suhsuh1106.github.io/Labyrinth_Bureau/`
- **내 컴퓨터에서**: Node 22가 필요합니다.

  ```bash
  npm install
  npm run dev        # 개발 서버 (http://localhost:5173)
  ```

### 개발 명령

| 명령 | 하는 일 |
|---|---|
| `npm run dev` | 개발 서버 |
| `npm test` | 테스트: 장부, 시장 규칙, 경쟁자, 몬스터, 담합, 근원, 화면 |
| `npm run typecheck` | 타입 검사 |
| `npm run sim -- --games 200 --style smart` | 시뮬레이션: 플레이어 봇 성향별 평균 순위, 1위 분포, 범람 횟수 (style: even, deep, hold, hire, smart, smartNoGuide, smartMine, smartNoRoot) |
| `npm run build` | 배포용 빌드 (`dist/`) |

PR을 올리면 GitHub Actions가 타입 검사, 테스트, 빌드, 시뮬레이션을 돌립니다.

## 한 달

1. **정보 주차**: 보고서·신문·소문·정보실·도감을 읽고, 조사 의뢰(시장·타 용병단)를 걸고, 정보망과 내정(건물·포션과 장비 사 두기·교회 후원·근원 기금)을 정합니다.
2. **탐험 주차**: 층별 우리 조·계약 조·조당 포션과 편성 줄(줄마다 꼭 챙길 직업·장비)을 정하고 결재 도장을 찍습니다. 모든 용병단이 미궁에 들어가고, 층마다 캔 것을 나눠 갖고, 그달에 같은 시세에 모두 팝니다.
3. **정산서**에 순위표, 층별 채집, 시세표, 귀환 보고(우리 파티 하나하나의 결과), 우리 정산, 그달의 **변경 일보**가 붙습니다.
4. 판은 이 브라우저에 자동으로 저장됩니다. 명패의 **새 게임** 단추로 처음부터 시작합니다.

## 들어 있는 규칙

| 규칙 | 내용 |
|---|---|
| 층과 시장 | 5층. 층마다 캘 수 있는 양이 한정돼 몰리면 나눠 갖고, 매달 절반쯤 다시 찹니다. 깊은 층은 모두의 성공이 쌓여야 함께 열립니다. 시세는 시장 전체 판매량이 수요를 넘으면 떨어집니다 |
| 경쟁 용병단 | 물량·안정·깊은 층·기회주의·투기·소형 성향의 7곳과 벌이에 따라 늘고 주는 군소 용병대. 판마다 성격이 조금씩 다르고, 큰 용병단은 계약 파티를 빌리고, 적자가 이어지면 허리띠를 졸라맵니다 |
| 몬스터와 편성 지침 | 층마다 판마다 다른 몬스터. 약점을 갖추면 성공률 +20%p, 역효과면 −15%p. 경쟁자는 한 층에 몇 달 드나들면 약점을 깨칩니다 |
| 포션과 세력 | 상단 포션(수요 따라 값)과 교회 성수 포션(조금 비싸고 한도가 있지만 사망을 더 줄임). 사는 쪽과 가까워집니다. 포션 수요와 사망이 쌓이면 상단과 교회가 함께 값을 올리고(담합), 교회 후원이 쌓이면 교회가 빠져 후원한 쪽에만 예전 값으로 팝니다 |
| 미궁의 압력과 근원 | 모두가 꺼낸 만큼 미궁이 차오르고, 이상 징후가 돈 뒤 넘치면 범람합니다. 우리 파티가 찾은 근원을 봉인(교회가 기금을 보탬)하면 미궁이 가라앉고, 채굴장을 내면 우리 몫이 늘지만 더 빨리 찹니다 |
| 변경 일보 | 상인 조합이 내는 신문. 지난달 기록만 읽어 1면을 꾸밉니다 |
