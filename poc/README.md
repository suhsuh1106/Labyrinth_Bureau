# 게임 시스템 PoC (Python)

`.claude/plan.md` 통합 기획서를 바탕으로 한 숫자 시뮬레이터입니다.
현재 메인은 **이사회 모드**(`play.py`)예요. 플레이어는 KPI를 설계하고, 부서가 알아서 움직이며, 보고서는 틀릴 수 있어요.
표준 라이브러리만 사용하며, 그래프(`--plot`)를 그릴 때만 matplotlib이 필요합니다.

## 파일

| 파일 | 역할 |
|------|------|
| `params.json` | 밸런스 수치 전부. 코드 수정 없이 여기만 바꿔서 실험 |
| `sim.py` | 시뮬레이션 코어. `begin_month` → `play_week` × 4 → `end_month`, 봇용 `step`은 한 달을 통째로 |
| `bots.py` | 자동 플레이 전략 봇 11종과 주간 계획(`plan_week`) |
| `run_batch.py` | 봇 대량 시뮬레이션, 한 판 추적, CSV·그래프 출력 (주간 직접 조작 모드) |
| `agenda.py` | 이사회 안건(부서장 제안), 모순 신호, 비서, 현장 판단, 부서장 브리핑 |
| `diplomacy.py` | 정치 심화: 빚 장부(부탁 · 청구), 경계도와 견제, 세력의 보고서 입수와 기만 판정, 감사 적발 공개/은폐 |
| `board_bots.py` | 이사회 모드 봇 (passive / politician / listener / reader / tuned) 대량 시뮬레이션 |
| `org.py` | 조직 레이어: 부서장, KPI 카드 슬롯, 부서 AI, 보고서 왜곡, 감사 |
| `play.py` | 이사회 모드로 직접 플레이 (메인) |
| `play_weekly.py` | 이전 버전: 매주 준비 활동과 탐사 범위를 직접 고르는 모드 |
| `ui.py` | 대시보드 막대·색상 |

## 환경

Unity 프로젝트 루트의 `.venv`(uv로 만든 Python 3.14 가상환경)를 사용합니다.
새로 세팅할 때는 프로젝트 루트에서 다음을 실행하세요.

```bash
uv venv
uv pip install -r poc/requirements.txt
```

### 활성화 (터미널을 열 때마다 한 번)

Git Bash (`poc` 폴더에서):

```bash
source ../.venv/Scripts/activate
export PYTHONIOENCODING=utf-8
```

PowerShell (`poc` 폴더에서):

```powershell
..\.venv\Scripts\Activate.ps1
$env:PYTHONIOENCODING="utf-8"
```

활성화하면 `python`이 venv의 Python을 가리킵니다. `PYTHONIOENCODING`은 한글 깨짐 방지용입니다.

## 실행

```bash
python run_batch.py                                  # 모든 봇 300판씩 요약 (1분 안팎)
python run_batch.py -n 1000 -b balanced -b deep_diver
python run_batch.py --trace balanced --seed 3        # 한 판을 월별로 추적
python run_batch.py --csv results.csv
python run_batch.py --plot                           # batch_plot.png 저장
python board_bots.py -n 300                          # 이사회 모드 봇 비교
python board_bots.py --trace tuned --seed 3          # 이사회 봇 한 판 추적
python play.py --seed 1                              # 이사회 모드
python play_weekly.py --seed 1                       # 이전 버전 (주간 직접 조작)
python play.py --no-color                            # 색상 코드가 글자로 보일 때
```

Git Bash에서 `play.py`처럼 키 입력을 받는 스크립트는 `winpty python play.py`로 실행해야 입력이 멈추지 않습니다.

## 이사회 모드 (play.py)

플레이어는 던전도, 탐사 결정도 직접 보지 않는다. **금고와 세력 우호도만 진짜 숫자**이고, 부서 보고는 틀릴 수 있다.

| 시점 | 할 일 |
|------|------|
| 창립 이사회 | 첫 달에 부서마다 후보 3명(이력서에 특성 하나 공개) 중 부서장을 직접 임명 |
| 월초 이사회 | 보고 (부서장 브리핑 + KPI ✔/✘ · 약속 장부와 신뢰 · ⚠ 모순 신호 · 소문 · 💡 드러난 특성) → 층 진출/최심부 공략 승인 → **📋 안건** 승인/거절 → `k` KPI 편집 · `g` 감사 · `f` 부서장 교체(후보 3명) · `r` 평판 조회 · `d` 세부 장부 → **정치 협상** → 세력 의뢰 → **이사회 결의 카드** |
| 4주 자동 진행 | 인사부·보급부가 월초에, 탐사부가 매주 KPI 점수를 최대화하도록 결정. 월초에 부서장이 약속을 하고, 탐사부가 매주 보고 |
| 현장 판단 | 후퇴, 보고된 사망 2명 이상, 탐사부가 대응하지 않은 정황 → 부서장들의 말 + 탐사부 판단의 다음 주 예상과, 다른 선택지의 얻는 것 · 잃는 것을 보고 지시. 한 달에 최대 2번, 차이가 작은 정황은 묻지 않음 |
| 예산 | 월초 `💰 예산 배정`: 부서장 요청(성향 · 정직도만큼 부풀림) → 이사회 배정. 덜 주면 조항 밖부터 자르고 보급부는 상단 외상, 더 주면 다 써 버림(부정직하면 착복). 설정: `org.budget` |
| 전초기지 · 층 매장 | 층 진출 승인 = 캠프 설치(설치비 · 월 유지비). 층 매출 = 손님 × 이해도 × 정비 × 가격 반응 × 구매액. 유지비를 못 받으면 노후 → 방치. 설정: `outposts` |
| 정치 심화 | 부탁(빚 1장) · 빚 청구, 경계도(소문으로만) · 견제, 세력은 보고값으로 반응하고 들키면 기만 판정, 감사 적발 공개/은폐. 설정: `diplomacy` |
| 비서 | 보고서 맨 위 한두 줄. 보이는 값만으로 "무엇을 비교해 볼지"만 짚음 |
| 층의 비밀 | 층마다 판마다 무작위 공략 공식(장비 계열 · 편성 · 준비 활동, 1~4층 1개 · 5층부터 2개). 탐사 중 단서가 쌓이고(정직하지 않은 부서장은 틀린 단서 · "확실" 과장), `p` 공략 지침으로 시험. 맞으면 난이도 ×0.62 · 손실 ×0.7. 발견 전에는 예측에 반영되지 않음. 설정: `params.json` → `secrets` |

코드: 안건 · 모순 신호 · 현장 판단 · 브리핑은 `agenda.py`, 부서장 특성 · 약속 장부는 `org.py`, 특성 수치는 `params.json` → `org.traits`

### 부서와 KPI 카드 (`params.json` → `org.kpis`)

| 부서 | 슬롯 | 스스로 정하는 것 | KPI 카드 |
|------|------|-----------------|----------|
| 탐사부 | 3 | 매주 탐사 범위·준비 활동 (세력 협력 포함) | 월 탐사 순이익 ≥, 월 사망자 상한 ≤, 월 이해도 증가 ≥, 세력 협력 우호도 사용 상한 ≤ |
| 인사부 | 2 | 보수 등급(저/중/고), 목표 인원, 힐러 수 | 월말 인원 ≥, 월 인건비 상한 ≤ (힐러 포함), 월말 부상자 상한 ≤, 인력 등급 ≥ (저/중/고 보수) |
| 보급부 | 2 | 장비 품질, 판매 마진 (0/20/40%) | 월 보급비 상한 ≤, 장비 등급 ≥, 월 보급 손익 ≥ |

- 부서는 **KPI에 없는 것은 신경 쓰지 않는다.** 예: 탐사부에 사망자 KPI가 없으면 사망을 무시하고, 우호도 사용 KPI가 없으면 세력 협력을 마구 쓴다.
- 부서장 성향: 공격형(수익·진척 중시) / 균형형 / 신중형(사망·우호도 사용 중시). 성향은 보이지만 **정직도는 감사 전까지 숨겨져 있다.**
- "월 탐사 순이익" = 탐험 수수료 + 전리품 차익(시장 판매 − 매입) − 준비 활동 비용 − 위약금. 월급·보급비·세금은 다른 부서와 이사회 몫이라, 탐사부가 달성해도 금고는 줄 수 있다.
- 수락한 **세력 의뢰는 탐사부 KPI 슬롯을 하나씩 차지**한다. 빈 슬롯이 없으면 기존 KPI를 빼야 수락할 수 있다.
- 힐러: 인사부가 고용 (1명이 모험가 10명 담당). 부상자 주간 회복률 15% → 힐러가 충분하면 60%. 인사부는 부상자 KPI가 없으면 힐러를 고용하지 않는다.

### 부서별 상세 보고

- 탐사부: 주별 성공·후퇴 → 탐험 수수료, 전리품 차익, 준비 활동(활동별 횟수), 위약금 → 순이익. 부상, 이해도, 세력 협력 우호도 사용
- 인사부: 월초 인원(지난달 보고한 월말 인원과 비교) → 이탈·사망·모집 → 월말 인원. 모험가 월급(1인 단가와 "인원 × 1인" 참고값), 힐러 고용, 홍보비, 월말 부상자
- 보급부: 물약·장비 수량 × 단가 (시세와 비교) = 구매비 → 판매 수입 → 보급 손익
- 감사한 부서는 항목마다 `[실제 …]`가 붙는다

### 세력 우호도와 정치 협상 (`params.json` → `politics`, `reactions`, `rumors`)

세력마다 **우호도**(−100~+100)가 있다. 높으면 혜택, 낮으면 불이익이고, 어느 세력이든 −100이 되면 게임 오버다.
세력끼리 견제(한쪽을 올리면 다른 쪽이 깎이는 규칙)는 없다. 정책 카드처럼 효과가 명시된 것만 다른 세력에 영향을 준다.

| 세력 | 적대 (−50↓) | 냉담 (−20↓) | 중립 | 우호 (+20↑) | 신뢰 (+50↑) |
|------|-----------|-----------|------|-----------|-----------|
| 상단: 소모품(물약·장비) 가격 | ×1.5 | ×1.15 | 기본 | ×0.9 | ×0.8 |
| 교회: 힐러 고용비·치료비 | ×1.5 | ×1.2 | 기본 | ×0.75 | ×0.5 |
| 국가: 세율 (수익 = 총수입 − 전리품 매입가, 매달) | 12% | 8% | 6% | 4% | 2% |

**우호도가 움직이는 이유 (월말, 플레이어에게는 숫자 없이 "세력 동향" 소문으로만 보인다)**

| 세력 | 오르는 행동 | 떨어지는 행동 |
|------|-----------|-------------|
| 상단 | 소모품을 많이 사들임 | 모험가에게 물건을 비싸게 팔기 (보급부 마진 10% 초과), 전리품 헐값 매입 (80% 미만) |
| 교회 | 사망자가 거의 없고 힐러를 둠 | 사망자, 박봉 (1인 월급이 기대 월급 미만), 방치된 부상자 (인원의 10% 초과) |
| 국가 | 탐사 성공률 60% 이상, 세수 증가, 새 층 해금 | 탐사 성공률 60% 미만, 세수 감소 |

그 밖에 의뢰 성공·실패, 정치 행동, 정책 카드, 세력 협력 요청(우호도를 소모)으로도 움직인다.

**정치 행동 (월 2회):** 상단 연회 개최 (금화 2,000 → 상단 +10), 교회 헌금 (금화 1,500 → 교회 +10), 국가 로비 (명성 60 → 국가 +10), 중재 회담 (명성 80 → 우호도가 가장 낮은 세력 +12)

명성 레벨업은 국가만 (층 허가 조건). 나머지 명성은 정치 행동에 쓴다.

### 이사회 결의 카드 (`params.json` → `policy_cards`)

| 카드 | 조직 효과 |
|------|----------|
| 상단 회계사 파견 | 보급부가 이번 달 있는 그대로 보고 (상단 +8) |
| 교회 고해성사 | 부서장 1명의 정직도 공개 (교회 +8) |
| 국가 감찰관 수용 | 사망자 교차 확인이 정확, 탐사부가 사망자를 1.5배 신경 씀 (국가 +10) |
| 성과급 제도 | 이번 달 전력 +5%, 모든 부서 보고 포장 1.5배 (금화 −3,000) |
| 긴축 명령 | 월급 −10%, 그만큼 이탈률 증가 |
| 내부 고발 제도 | 무작위 부서 1곳 무료 감사 |
| 부서장 윤리 연수 | 부서장 전원 정직도 영구 상승 (금화 −2,000) |
| 시장 개방 / 이단 심문 / 국가 징집 / 중립 유지 | 세력 우호도 조정 (정치 카드) |

### 보고서 왜곡

- 보고값 = 실제값 × (1 ± 정직도 × KPI 압박 × 0.5) × (1 + 노이즈 2%). 야심가는 포장 ×1.5, 원칙주의는 포장 없음, 현장파는 노이즈 두 배
- 모순 신호: 부서 보고(탐사 순이익 + 보급 손익 − 인건비 − 홍보비)의 포장분과 장부 밖 리베이트의 합이 max(2,000G, 수익 × 5%)를 넘으면 경고
- 약속: 월초에 첫 번째 KPI를 두고 약속. (1 − 정직도) 확률로 솔직하게 말한다. 월말에 실제값으로 판정해 신뢰 기록을 남긴다
  - KPI 압박 = 목표에 못 미친 정도 (0~1). KPI가 없는 지표는 노이즈만 붙는다.
  - 부풀리는 지표: 수익, 이해도, 인원. 줄이는 지표: 사망자, 인건비, 보급비, 우호도 사용. 장비 등급은 속일 수 없다.
- 감사 (부서당 1,500G): 다음 달 보고서에 그 부서의 실제값을 함께 보여주고, 15% 넘게 틀리면 허위 보고로 적발. 감사하면 부서장 정직도가 공개된다.
- 긴급 감사: 경보 중에 이번 주 실제 수익·사망을 바로 확인
- 교차 확인: 국가가 독자적으로 집계한 사망자 수 (오차 ±12%)
- 부서장 교체 (퇴직금 1,000G): 후보 3명 중 선택. 후보마다 특성 하나가 알려져 있다
- 부서장 특성: 부서 특성 1개 + 60% 확률로 공통 특성 1개. 숨은 특성은 매달 35% 확률로 드러나고, 평판 조회(500G)로 하나를 바로 알 수 있다

## 이전 버전: 주간 직접 조작 (play_weekly.py)

| 시점 | 할 일 |
|------|------|
| 월초 | 대시보드 확인 → 세력 의뢰 수락 (세력별 1장씩 제시, 최대 2장) → 정책 카드 (월초에 바로 적용). `p`로 상시 정책 변경 |
| 매주 (4번) | 수락한 의뢰 진행도와 지난주 탐사 보고서의 정황 확인 → 준비 활동 최대 2개 → 탐사 범위 (활동을 반영한 범위별 성공률·예상 손실·예상 수익 표) → 이번 주 보고서 |
| 월말 | 정산 (수입·지출, 의뢰 성공·실패, 명성 레벨업, 적자 판정) |

- 층 이동: 현재 층 이해도가 0.7을 넘으면 다음 층으로 갈지 매주 묻는다
- 상시 정책: 목표 인원, 보수 등급 저/중/고 (월급과 인력 등급이 함께 정해짐), 장비 품질, 편성, 전리품 매입 비율
- 공급처 고정: 장비는 상단, 물약은 교회에서 사고, 전리품은 시장에 판다
- 자동: 홍보비 (부족 인원 × 100G), 물약·장비 발주량과 판매가, 세력 레벨업 (우호도 높은 세력부터)
- `a`: 월초에 누르면 그달 전체를, 매주 누르면 그 주를 봇이 대신 결정

### 세력 의뢰 (`params.json` → `requests`)

월초에 세력마다 1장씩 제시되고 최대 2장을 수락한다. 매주 탐사 결과로 진행도가 쌓이고, 월말에 판정한다.
세력 우호도는 **의뢰로 벌고, 협력 활동으로 쓰고, 정책 카드로 조정**한다.

| 세력 | 의뢰 성향 | 예시 |
|------|----------|------|
| 상단 | 금화 보상, 넓은 탐사·꾸준한 물량 | 광석 운송(범위 70%+ 2주 성공), 신규 광맥 조사, 호위 실적, 대량 납품 |
| 교회 | 명성 보상, 인명·성유물 | 성유물 회수, 순례자 안전(사망 2명 이하), 역병 구호, 사제 수련 동행 |
| 국가 | 진척·통제 | 심층 정찰(최전선 층 3주 성공), 신규 구역 개척(층 해금), 기사단 합동 작전, 몬스터 토벌 |

조건 종류: `weeks`(범위·성공·최전선·활동 조건을 만족한 주 수), `seize`(특정 정황을 대응하거나 살림), `unlock`(이번 달 층 해금), `max_dead`(이번 달 사망자 상한). 정황형(`seize`) 의뢰는 정황이 안 뜰 수도 있어서 실패해도 불이익이 없다.

### 준비 활동 (`params.json` → `activities`)

| 활동 | 효과 | 대가 |
|------|------|------|
| 정찰 선발대 | 성공률 +10%p | 보상 −15% |
| 물약 추가 지급 | 손실 −40% | 1인당 20G |
| 집중 훈련 | 전력 영구 +3% (최대 +30%) | 이번 주 탐사 인원 −30% |
| 지도 연구 | 이해도 +0.08 | 행동력만 |
| 부상자 치료 | 부상자 전원 복귀 | 1인당 150G |
| 교회 사제 동행 | 손실 −60% | 교회 우호도 −8 |
| 상단 호위대 | 성공률 +8%p, 보상 +15% | 상단 우호도 −8 |
| 국가 기사단 지원 | 성공률 +18%p | 국가 우호도 −12 |

세력 협력 활동은 그 세력 우호도가 0 이상일 때만 쓸 수 있다.

### 탐사 보고서 정황 (`params.json` → `findings`)

매주 탐사가 끝나면 정황 하나가 보고되고 다음 주 탐사에 영향을 준다. 대응 활동을 고르면 막거나 기회로 바꿀 수 있다.

| 정황 | 대비 없으면 | 대응 |
|------|------------|------|
| 함정 지대 발견 | 성공률 −15%p | 정찰 선발대 → 오히려 +5%p |
| 몬스터 무리 활발 | 난이도 +30% | 국가 기사단 또는 교회 사제 |
| 보급로 습격 소문 | 물약 효과 없음 | 상단 호위대 |
| 야영지 역병 | 부상 회복 없음, 손실 +30% | 부상자 치료 또는 교회 사제 |
| 희귀 광맥 흔적 | – | 탐사 범위 70% 이상이면 보상 +50% |
| 고대 지도 조각 | – | 지도 연구 시 이해도 +0.15 추가 |
| 성유물 기운 | – | 교회 사제 동행 시 교회 우호도 +12, 보상 +20% |
| 특이사항 없음 | – | – |

|----|------|
| balanced | 기획서 시나리오대로 성장, 우호도가 가장 낮은 세력의 의뢰를 수락해 균형. 탐사 범위는 기대값으로 선택 (다른 봇도 대부분 같은 방식) |

## 기획서에 없어서 임시로 정한 공식 (sim.py)

- **탐험 성공 확률** = 1 / (1 + (난이도 / 전력)⁴)
  - 전력 = 등급 평균 × 장비 × 물약 × 이해도 보너스
  - 난이도 = 층 기본값 × (0.5 + 1.1 × 탐사 범위)
  - 매주 이 확률로 **성공/후퇴를 판정**
- **보상** = 층 보상 × (0.6 + 0.8 × 탐사 범위). 후퇴하면 25%만 가져오고 이해도도 절반만 쌓임
  - 난이도가 보상보다 탐사 범위에 더 가파르게 반응해서, 전력에 맞는 범위가 따로 있음
- **손실률** = 0.06 × (난이도 / 전력) + (후퇴 시) 0.2 × 탐사 범위. 전투형 과반이면 감소
  - 보상·손실·이해도 수치는 한 달 기준이고, 주간 탐사는 이를 4로 나눠 쓴다 (이해도는 4주 누적이 월 기준과 같도록 환산)
  - 손실의 절반은 사망(위약금), 절반은 부상(주당 15% 자연 회복, 힐러가 충분하면 60%, 월급은 계속 지급)
- **이탈률** = 8% − 0.1 × (월급 / 기대 월급 − 1) + 전리품 매입 비율 효과
  - **기대 월급(위험 수당)** = 1,000G × (1 + 0.045 × (탐사 층 − 1)). 이사회 모드의 보수 등급 월급(저 0.9 · 중 1.2 · 고 1.5배)과 교회 박봉 기준도 이를 따름
- **층 해금**: 현재 층 이해도 0.7 이상이면 다음 층이 열림 (이해도 증가량 0.42 × (1 − 현재 이해도), 후퇴 시 절반). 5·8·10층은 국가 Lv.1·2·3 필요
- **세력 우호도**: 세력별로 독립 (견제 없음). 월말에 길드 행동에 따라 오르내림 (위 표). 적대(−50 미만)면 제재, **−100이 되면 게임 오버 (세력 붕괴)**
  - 국가 레벨업(층 허가)에는 명성과 함께 국가 우호도 20 이상이 필요
- **승리 (이사회 모드)**: 10층 이해도 0.7 이상이면 탐사부가 최심부 공략 승인을 요청 (추정 성공률은 부서장 정직도 × 0.25만큼 부풀려 보고). 승인한 달에 범위 90% 이상으로 돌파하고, 실제 성공 확률 50% 이상, 인원 50명 이상이면 승리
- **세금** = (총수입 − 전리품 매입가) × 세율
- **명성 모드**: `rules.reputation_mode`를 `accumulate`(축적형)나 `use_or_lose`(소모형)로 바꿔 미정 사항을 비교해 볼 수 있음
